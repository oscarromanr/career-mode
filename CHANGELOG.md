# Changelog

## 1.0.0 — 2026-08-07 — Architecture migration release

### Phase model (save v4)

- Save format v4: phase moved under `session` (`{ phase, overlay,
  pendingEffects }`); migrations v1/v2/v3 -> v4 are tested one-way.
- Modal flags (`triggerNaturalizationModal`, `triggerNtCallUpModal`) replaced
  with an explicit pending-effects queue; reload during summary,
  naturalization, and national-team prompts resumes the correct flow.
- Runtime validation rejects malformed/unknown saves with a user-readable
  error; the current save is preserved until a replacement succeeds.

### Domain modularization

- `js/engine.js` is now a thin facade; all rules live in `js/domain/*`
  (rng, model, player, decisions, agents, career, contracts, offers,
  boosters-shop, season, national-team, summary). No DOM, no translation
  globals, injectable RNG. See `plans/MODULE-MAP.md`.
- Removed duplicate legacy agent/contract sub-modules.

### Tooling

- Vite build (`npm run build`), strict TypeScript (`npm run typecheck`),
  Vitest (`npm test`), GitHub Pages deploy with CNAME preserved.
- Typed contracts in `src/domain/types.ts`; typed state facade in
  `src/domain/state.ts`.

### Deterministic simulation

- Seeded PRNG (mulberry32); every career stores `rngSeed`/`rngCursor`.
- Same seed + action sequence reproduces the same career; new
  "Export debug report" menu item includes seed, cursor, phase, and recent
  actions for bug reports.

### Decision data

- All 312 decision cards converted to one canonical `options[]` schema
  (`js/data-decisions-canonical.js`), generated by
  `scripts/convert-decisions.js`.
- Spanish translations converted to nested `I18N_ES.decisions[id]` entries;
  flat-key compatibility lookup removed; missing ES falls back to English,
  never to internal keys.
- `npm run validate:data` gates CI (unique IDs, option counts, effect keys,
  positions, ES fallback sanity).

### Testing & QA

- Playwright browser suite: career loop, legacy import migration, malformed
  import recovery, reload behavior. Console errors fail the suite.
- Responsive visual screenshots for setup/academy/decision at desktop,
  tablet, and mobile.
- Invariant, reload, persistence/replay, and domain unit suites.

### Decision record

- React UI migration explicitly deferred: `docs/adr/001-react-deferred.md`.
